# Release notes — 8.0.3

## en-US

Meet Meadow — a full visual redesign across every screen: Quick Calculator, Semester, Marks, History, Settings, and Onboarding.

- New GPA tooltips on History & Quick cards (hover / long-press)
- Clearer Predict screen with a renamed Target Cumulative GPA
- More precise semester GPA in History (3 decimal places)
- Redesigned bottom sheets and navigation throughout
- Faster app startup
- Countless polish and bug fixes
